# Proyecto final: Sistema de Rol de Pagos con control de versiones y seguridad web

Este repositorio contiene una simulación de control de versiones y seguridad web aplicada a un sistema de rol de pagos.

El sistema simulado incluye:

- Login con usuario y contraseña.
- Validación de contraseña robusta.
- Código de verificación enviado al teléfono móvil.
- Registro de cambios mediante GitHub.
- Simulación de error de seguridad.
- Retorno a una versión anterior estable.
- Corrección final para producción.

## Objetivo del proyecto

Integrar GitHub con buenas prácticas de seguridad web, centrándose en los cambios de seguridad surgidos durante el desarrollo de una aplicación web.

## Archivos del proyecto

- `README.md`: descripción general del proyecto.
- `manual-validacion-contrasenas.md`: manual de validación de contraseñas robustas.
- `diagrama-login-2fa.md`: diagrama del proceso de login, password y código móvil.
- `registro-control-versiones.md`: simulación de versiones, error, retorno y corrección.
